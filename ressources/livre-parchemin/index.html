Livre/Parchemin Ressource

PARCHEMIN

Les parchemins sont des papiers préparés à l’avance pour accueillir un sort. Il est nécessaire d’avoir la bonne magie et la bonne puissance magique pour pouvoir utiliser le sort indiqué sur le parchemin ou même simplement le lire. Les parchemins possèdent différents niveaux de puissance :
NPM 1 : Parchemin vierge
NPM 2 : Grand parchemin gravé
NPM 3 : Super parchemin gravé
NPM 4 : Méga parchemin gravé
NPM 5 : Ultra parchemin gravé

Il est assez simple pour reconnaître les niveaux de puissance des parchemins, vu qu’ils ont des sorts plus puissants, ils sont beaucoup plus colorés. Couleur en rapport avec la magie du sort, le niveau 1 est un peu coloré mais garde son teint beige alors que le niveau 5 est entièrement de la couleur de la magie.

Et aussi pas la même durée pour pouvoir y inscrire le sort ou le graver :
NPM 1 - 2 : 1 jet d’artisanat réussi sur une journée. (1 jet par jour maximum)
NPM 3 - 4 : 2 jets d’artisanat réussis sur 2 jours. (1 jet par jour maximum)
NPM 5 : 3 jets d’artisanat réussis sur 3 jours. (1 jet par jour maximum)

Plume pour gravure = Une plume spéciale qui permet à un personnage avec le métier de Scribe de graver les parchemins.

Parchemin vierge = Un parchemin utile pour écrire dessus, on peut également le graver.

Parchemin gravé = Un parchemin avec des gravures dessus, il est sans sort et il est prêt à accueillir un sort de son niveau. Pour les gravés, il est nécessaire d’avoir

Parchemin niveau X = Un parchemin contenant un sort, pour le connaître il suffit de se fier à la couleur du parchemin et à ce qui est écrit dessus.

Utiliser un sort sur un parchemin consomme normalement le chakra et c’est qu’une seule utilisation.

LIVRE

Les livres sont des objets permettant pas mal de choses mais les deux utilités qui vont nous intéresser c’est :

  • Permettre d’obtenir 1 NM pour un sort.
  • Apprendre une magie.

Les premiers sont des livres qui, une fois lus, confèrent un NM à un sort spécifique.
À noter : le NM obtenu par un livre reste lié au sort concerné, contrairement aux NM acquis via la montée en niveau du personnage, qui eux peuvent être réaffectés librement. Si un personnage retire un sort auquel est lié un NM provenant d’un livre, ce NM est mis en attente tant que le sort n’est pas réintégré dans la liste du personnage. Une fois le sort repris, le NM est automatiquement réactivé. C’est qu’un seul NM par sort obtenable par les livres.

Ces livres-là prennent 1 jet par niveau de puissance magique du sort en question. (1 jet par jour maximum)

Puis, il existe les livres de magie.
Ces ouvrages très rares permettent à ceux qui parviennent à les lire entièrement d’acquérir une nouvelle magie, à condition bien sûr que cela soit compatible avec leur magie innée.

Ces livres-là demandent 8 jets de magie/concentration réussis pour le finir. (1 jet par jour maximum)

Le Livre du Rien = Ce livre particulier, totalement transparent, permet à celui qui le lit d’oublier une magie acquise. Cependant, attention : renoncer à une magie est souvent mal vu, et ce choix peut avoir des conséquences négatives.

Une fois un livre terminé, le texte à l’intérieur du livre aura disparu, perdant toute sa valeur.
