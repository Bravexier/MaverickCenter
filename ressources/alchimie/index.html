Alchimie Ressource

Les potions dans Maverick sont des préparations alchimiques qui permettent de soigner de nombreux maux comme pourraient le faire certains sortilèges. Elles ne remplacent pas forcément les sorts mais sont parfois utiles pour se tirer d’une situation épineuse rapidement.

Elles sont également utilisées pour les soins à long terme, des blessures profondes qui demandent du temps pour être soignées, les potions peuvent faire office de traitement pour éviter de solliciter la magie tout le temps.

On utilise des fioles de verre pour garder le précieux liquide, il en existe 4 sortes qui sont adaptées pour différents niveaux de puissance de potions. Elles se reconnaissent car n’ont pas la même forme, plus la potion est puissante, plus la fiole est élaborée.

Type de fiole en verreNiveauNombre d’ingrédients
Petite fioleNovice2 ingrédients
Fiole moyenneApprenti3 ingrédients
Super fioleAvancé4 ingrédients
Méga fioleExpert, Maître5 ou plus ingrédients

Bien qu’on connaisse la puissance des fioles, il faut également comprendre comment fonctionne chaque ingrédient. Chaque ingrédient possède une catégorie. Chaque ingrédient indiqué dans une recette représente deux unités de cet ingrédient.

Ingrédient 1Ingrédient 2Ingrédient 3Ingrédient 4Ingrédient 5Ingrédient 6
SolvantEssenceAmplificateurCatalyseurStabilisateurAmplificateur majeur
Exemple : Eau, Huile, etc …Exemple : GeléeExemple : Poudre colorée, fruitExemple : gelée supérieureExemple : fruit magiqueExemple : fruit magique

Le niveau de puissance de la potion explique également qu’il faut un bon matériel pour prétendre faire une potion dans de bonnes conditions. L’alchimiste et l’apothicaire utilisent les mêmes kits.

Kit d’alchimiePrixPermet …
Kit du petit alchimiste10 RoFaire les recettes novice
Kit de l’apprenti alchimiste20 RoFaire les recettes apprentis ou moins
Kit de l’alchimiste avancé40 RoFaire les recettes avancées ou moins
Kit de l’expert alchimiste80 RoFaire les recettes experts ou moins
Kit du maître alchimiste160 RoFaire les recettes maîtres ou moins

Donc en résumé : Une potion peut donc être :

  • 2 ingrédients → Solvant x 2 + Essence x 2 = Petite fiole
  • 3 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 = Fiole moyenne
  • 4 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 + Catalyseur x 2 = Super fiole
  • 5 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 + Catalyseur x 2 + Stabilisateur x 2 = Méga fiole
  • 6 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 + Catalyseur x 2 + Stabilisateur x 2 + Amplificateur majeur x 2 = Ultime fiole
