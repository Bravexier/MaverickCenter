ravageur

  • 2 cibles (Bimane)Don
    Si la première arme est suffisante pour mettre hors combat une cible, le deuxième coup peut toucher une autre cible à portée (dégâts /2).
  • Bien s'en servir (Bimane)Don
    Permet de faire un coup unique avec les deux armes. L'armure ennemie n'est prise en compte qu'une fois.
  • Directrice (Bimane)Don
    Le malus de l'ambidextrie est annulé pour la main directrice mais repasse à 20% pour la main secondaire.
  • Poigne du Titan (Bimane)Don
    Permet d'utiliser une arme à deux mains comme une arme à une main.
  • Poigne ferme (Bimane)Don
    +4 AP lors d'une parade partielle avec deux armes.
  • Poigne forte (Bimane)Don
    +4 dégâts avec les deux armes.
  • Ravageur (Bimane)Don
    +5% Arme lourde, +5% Athlétisme, +5% Vigueur, +2 points de maîtrise d'arme à répartir.
