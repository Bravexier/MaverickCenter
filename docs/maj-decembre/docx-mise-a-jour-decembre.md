Armes

- Les matériaux pour les armes vont avoir de nouveaux effets secondaires (leur boost de dégâts ne change pas)

- **Acier** : Une fois par combat, permet de relancer les dés de dégâts, mais le second résultat doit être conservé.

- **Fer noir** : Si la cible ne possède pas de corruption, lui inflige 4 points de corruption. Si elle possède déjà de la corruption, inflige +2 dégâts et 2 de corruption.

- **Argent** : +1 dé de dégâts contre les non-morts.

- **Fonte** : −1 cran de solidité.

- **Cuivre** : Les sorts de type « Fer » appliqués à l'arme durent un tour supplémentaire, soit 4 tours au lieu de 3.

- **Bronze** : +1 cran de solidité.

- **Os** : +1 dé de dégâts contre les bêtes.

- **Laiton** : +1 dé de dégâts contre les créatures mécaniques ou inertes.

- **Or** : +1 dé de dégâts contre les démons.

- **Vif-argent** : Permet de toucher les êtres immatériels.

- **Mythril** : Si l'arme touche une barrière, elle inflige +1 dé de dégâts.

- **Titane** : Avantage contre les effets de désarmement.

- **Maverium** : Si la créature ne possède pas ou plus de barrière, l'arme inflige +1 dé de dégâts.
