Les potions dans Maverick sont des préparations alchimiques qui permettent de soigner de nombreux maux comme pourrait le faire certains sortilèges. Elles ne remplacent pas forcément les sorts mais sont parfois utiles pour se tirer d’une situation épineuse rapidement.

Elles sont également utilisées pour les soins à long terme, des blessures profondes qui demandent du temps pour être soigné, les potions peuvent faire office de traitement pour éviter de solliciter la magie tout le temps.

On utilise des fioles de verre pour garder le précieux liquide, il en existe 4 sortes qui sont adaptées pour différents niveaux de puissance de potions. Elles se reconnaissent car n’ont pas la même forme, plus la potion est puissante, plus la fiole est élaborée.

| Type de fiole en verre | Niveau | Nombre d’ingrédient |
| :-: | :-: | :-: |
| Petite fiole | Novice | 2 ingrédients |
| Fiole moyenne | Apprenti | 3 ingrédients |
| Super fiole | Avancé | 4 ingrédients |
| Méga fiole | Expert, Maître | 5 ou plus ingrédients |

Bien qu’on connaisse la puissance des fioles, il faut également comprendre comment fonctionne chaque ingrédient. Chaque ingrédient possède une catégorie. Chaque ingrédient indiqué dans une recette représente deux unités de cet ingrédient.

| Ingrédient 1 | Ingrédient 2 | Ingrédient 3 | Ingrédient 4 | Ingrédient 5 | Ingrédient 6 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| Solvant | Essence | Amplificateur | Catalyseur | Stabilisateur | Amplificateur majeur |
| Exemple : Eau, Huile, ect … | Exemple : Gelée | Exemple : Poudre coloré, fruit | Exemple : gelée supérieur | Exemple : fruit magique | Exemple : fruit magique |

Le niveau de puissance de la potion explique également qu’il faut un bon matériel pour prétendre faire une potion dans de bonnes conditions. L’alchimiste et l'apothicaire utilisent les mêmes kits.

| Kit d’alchimie | Prix | Permet … |
| :-: | :-: | :-: |
| Kit du petit alchimiste | 10 Ro | Faire les recettes novice |
| Kit de l’apprenti alchimiste | 20 Ro | Faire les recettes apprentis ou moins |
| Kit de l’alchimiste avancé | 40 Ro | Faire les recettes avancées ou moins |
| Kit de l'expert alchimiste | 80 Ro | Faire les recettes experts ou moins |
| Kit du maître alchimiste | 160 Ro | Faire les recettes maîtres ou moins |

Donc en résumé : Une potion peut donc être :

- 2 ingrédients → Solvant x 2 + Essence x 2 = Petite fiole
- 3 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 = Fiole moyenne
- 4 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 + Catalyseur x 2 = Super fiole
- 5 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 + Catalyseur x 2 + Stabilisateur x 2 = Méga fiole
- 6 ingrédients → Solvant x 2 + Essence x 2 + Amplificateur x 2 + Catalyseur x 2 + Stabilisateur x 2 + Amplificateur majeur x 2 = Ultime fiole
