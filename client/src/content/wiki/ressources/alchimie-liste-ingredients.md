Nombreux sont les ingrédients qui doivent être rassemblés dans les différentes catégories.

## Solvant

Le solvant est la base liquide de toute potion. Il sert de support alchimique et permet de dissoudre les autres ingrédients afin de stabiliser la préparation. Le type de solvant utilisé détermine généralement la catégorie de potion produite (fiole, remède, huile ou philtre).

| ***Ingrédient*** | ***Type*** | ***Affinité*** |
| :-: | :-: | :-: |
| Eau | Liquide | Fiole |
| Sérum | Liquide | Remède |
| Huile | Liquide | Huile |
| Alcool | Liquide | Philtre |

## Amplificateur

L’amplificateur renforce l’essence présente dans la potion. Il intensifie l’affinité dominante du mélange, permettant d’augmenter l’efficacité ou la puissance de l’effet obtenu. Certains ingrédient possède la mention (majeur), ils sont utiles pour faire les potions ultimes. Parfois certaines potions ne peuvent pas marcher avec seulement l’essence et c’est le mélange avec un amplificateur qui permet un résultat.
