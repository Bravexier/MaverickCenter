alias

Alias d'une page (frontmatter `aliases`) : autres noms utilisables dans [[ ]]. `texte` garde l'écriture d'origine ; `cle` est sa forme normalisée (casse, accents, apostrophes ignorés), celle qui sert à retrouver la page (vue cle_page).

4 colonnes
ColonneTypeCléDescription
page_idTEXTclé primaire, → page
ordreINTEGERclé primairerang dans la liste `aliases:` (0 = premier) : l'ordre est conservé
texteTEXT
cleTEXTnormalize(texte), calculé par l'importeur ; client/scripts/db-derive.mjs le vérifie
