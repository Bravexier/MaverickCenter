ethnie

ETHNIE : une ligne par ligne de l'onglet « Bonus Race » (96) : sous-race, origine ou variété d'une race (« Elfe Noir Charbon », « Drakos Rouge », « Mort-Vivant Eau », « Orios de Terre »…). La clé de la source est le nom (col. B).

18 colonnes
ColonneTypeCléDescription
idTEXTclé primaire'<race.id>#ethnie:<slug>'
race_idTEXT→ racerace de rattachement, déduite de la col. A (« Race ») après rapprochement des noms
slugTEXT
nomTEXTcol. B (sans en-tête dans la source) : valeur que le joueur choisit dans la fiche
ordreINTEGERrang de la ligne dans l'onglet (ligne 2 = 1) ; ordre d'affichage
libelleTEXTcol. C « Nom », telle qu'écrite ('Adaptation humaine', 'Sang corrompu', 'Terre ' avec son espace final) ; NULL pour Elfe Doré, Majin, Hujin, Lamia (cellule vide). Pour 14 races c'est le nom de la magie innée liée.
magie_idTEXT→ magiemagie dont le nom est `libelle` (comparaison sans casse, sans accent, sans espace parasite) ; NULL sinon. La fiche s'en sert pour imposer l'ethnie par la magie innée choisie (BDD!X2).
descriptifTEXTcol. D « Descriptif », texte multiligne tel qu'écrit (puces « - » comprises) ; seule description de l'effet
race_brutTEXTcol. A « Race » telle qu'écrite : 'Felfle' (coquille), 'Satyre ' (espace final), 'Elfe Forestier' (casse). Conservée pour que les anomalies de la source restent visibles (voir design.md §12, points ouverts).
bonus_pvINTEGER
bonus_chakraINTEGER
bonus_barriereINTEGER
bonus_apINTEGER
bonus_amINTEGER
bonus_vitesseINTEGER
origineTEXT
source_refTEXT« Fiche auto V15.2.2 › Bonus Race › A6:N6 »
remarqueTEXTremarque ou information supplémentaire (texte libre, vide par défaut) ; reprend les notes de cellule du classeur de la ligne
