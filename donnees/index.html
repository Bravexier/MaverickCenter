DB : la base de données

Les données structurées du jeu, telles qu’elles sont rangées dans la base : 168 tables (27 674 lignes) et 35 vues. Chaque ligne garde le texte de sa source ; une valeur absente est marquée ∅ et n’est jamais remplacée par une valeur inventée. Les identifiants et les clés étrangères sont des liens : un sort renvoie à sa magie, une capacité à sa page du wiki. Le texte intégral des pages est dans le wiki.

Déboguer avec un outil externe : télécharger la base SQLite (lecture seule, reconstruite à chaque publication à partir de data/rows). À ouvrir avec DB Browser for SQLite ou sqlite3 maverick.db ; la structure de chaque table est décrite ci-dessous.
