v_mode_hyper_lectures

Vue : calculée à partir d’autres tables, toujours à jour. Les cinq LECTURES du mode hyper (mode_hyper_effet.version) sur une même ligne : une ligne par cible (magie, couple de magies ou race) et variante. Chaque colonne est le texte de la source, NULL quand cette source ne dit rien de cette cible ; `nb_textes` = nombre de textes distincts (1 = les sources concordent). Les effets « généraux » n'ont pas de clé commune entre les sources : ils restent dans mode_hyper_effet.
